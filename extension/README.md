# Extension « Le 11 parfait pour MPG »

Ajoute un bouton **11 parfait** sur le site mpg.football : il affiche ton meilleur 11,
ton banc dans l'ordre et la probabilité de titularisation de chaque joueur, calculés
par ton instance de l'app.

## Installation (Chrome, Edge, Brave)

1. Ouvre `chrome://extensions` et active le **mode développeur**.
2. **Charger l'extension non empaquetée**, puis choisis ce dossier `extension/`.
3. Clique sur l'icône de l'extension : colle l'adresse de ton app (ex. `https://ton-app.vercel.app`)
   et le code de partage de ta ligue (dans l'app : ta ligue, puis « Copier le code de partage »).
4. Va sur mpg.football et touche le bouton **11 parfait** en bas à droite.

L'extension n'envoie que la liste des joueurs de ta ligue à ton app ; elle ne lit
rien sur la page MPG.
